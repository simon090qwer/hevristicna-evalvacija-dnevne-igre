# Primerjalna hevristična evalvacija ročno in z umetno inteligenco zasnovanih uporabniških vmesnikov 

Gradivo k diplomskemu delu, UM FERI, Medijske komunikacije, 2026. 
Avtor: Simon Slemenšek. Mentor: izr. prof. dr. Boštjan Šumak. 

Repozitorij vsebuje celotno evalvacijsko gradivo: 28 zaslonov štirih prototipov, poziv, navodila ocenjevalcem, ocenjevalni inštrument, surove podatke obeh krogov in preglednico izračuna rezultatov. 

## Oznake prototipov 
A – Visily, B – ročno oblikovan prototip, C – Uizard, D – Figma Make. Med ocenjevanjem ocenjevalci te povezave niso poznali. 

## Struktura 
- `zasloni/` – zasloni posameznega prototipa v izvorni ločljivosti
- `ocenjevanje/` – navodila, inštrument in izpolnjene ocene, ocenjevalci 1–3
- `analiza/` – izračun ocen, skupnih ocen in Kendallovega koeficienta
- `poziv.txt` – poziv, uporabljen pri vseh treh orodjih 

Podatki ocenjevalcev so anonimizirani.
